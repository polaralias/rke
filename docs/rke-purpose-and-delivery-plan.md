# Product purpose

RKE 0.1.0 supports a dependable path from engineering intent to existing implementation, evidence and maintained documentation. EWF owns reasoning and outcomes; the optional RKE adapter owns machine support; OKF Tasks owns durable execution records. Retrieval, explicit bindings and source review help an agent keep implementation and documentation consistent.

Use [acceptance requirements](repository-intelligence-acceptance.md), [capabilities](knowledge/code-context.md) and [qualification](release-qualification-contract.md). Features and deterministic checks do not prove agent effectiveness.
