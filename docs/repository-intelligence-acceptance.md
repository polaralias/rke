# Repository intelligence acceptance

Scope baseline: 15 October 2026. This independently authored contract implements WS0 of the completion plan. It compares user outcomes, not command counts, formats or internal implementation. G0 original-skill fidelity is independently tracked in [the legacy matrix](legacy-skill-parity-matrix.md).

These independently authored requirements describe RKE user outcomes and deliberate limits. They are acceptance criteria, not evidence of current agent effectiveness.

All rows are must-have and currently `partial`: code support plus deterministic tests cannot close the agent, browser, host or human portion. The machine-readable [scenario inventory](../tests/fixtures/targeted-parity-scenarios.json) names positive/adversarial acceptance and evidence owners. These are scope decisions for the initial runtime, not independent sign-off or measured results. The [release qualification gate](release-qualification-contract.md) refuses promotion without current evidence.

No unrestricted summarisation, mandatory model/provider, vector index, automatic knowledge promotion or universal performance claim is required. The six-snapshot/four-language held-out study remains the benefit test. Runtime-only fixtures cannot establish superiority, faster navigation or lower cost. Single-root and multi-root evidence, read-only explanation and mutation/closure evidence must remain separately identified.
