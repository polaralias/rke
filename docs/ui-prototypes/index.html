RKEKanban + reader / Five design directionsReview notes

Five ways to work with knowledge.

Ten static pages. Five distinct visual systems. Explore the same tasks and document in each direction, then choose the elements you want to carry into RKE.

These are visual prototypes with example content. Search, filters, task previews, reading controls and navigation work locally. Nothing connects to your repository.

01 / Clean viewStillGeist

A quiet workspace with flat surfaces, restrained metadata and a single navigation rail.
