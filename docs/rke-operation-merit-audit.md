# Runtime operation scope

The current release contract validates 62 shared operations, with the same handlers behind CLI and MCP. Operation count is an interface inventory, not evidence of engineering benefit.

Retrieval and structural evidence support comprehension and delivery; knowledge validation and freshness support deliberate documentation review; optional continuity supports handoff and pickup; coordination, host maintenance, selected workspaces and the reader activate only for their relevant requests. Ordinary corrections do not require persistent state, generated explanations, a reader or Tasks.

Keep operations only where deterministic execution adds useful evidence or enforces a concrete boundary. EWF remains the authority for engineering judgement.
