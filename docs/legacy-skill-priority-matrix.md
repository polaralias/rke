## Priority rule

- **P0:** can falsely assert closure, safety, verified runtime, or external publication; can lose work; or blocks trustworthy evaluation of all other cases.
- **P1:** can degrade design, comprehension, knowledge, or continuation quality without the same immediate irreversible consequence.
- **P2:** explicit negative routing that must remain guarded but is outside EWF's replication claim.

Within a priority, work in the numbered order below. A later row may be probed in parallel, but it is not signed off until its dependencies and its own positive and adversarial evidence pass. “Runtime green” means only the 13 opt-in deterministic probes pass; it does not imply agent or provider parity. No row is complete merely because an alias routes or a skill reference exists.
