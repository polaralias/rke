# Initial runtime delivery scope

Deliver a bounded local repository intelligence runtime: SQLite retrieval and freshness, syntax-derived structure, explicit knowledge validation and bindings, optional continuity, CLI/MCP parity, selected multi-root views and a local reader. EWF owns engineering judgement; the adapter selects useful machine support; OKF Tasks owns durable execution records.

The first build is RKE 0.1.0. Keep current acceptance in [repository intelligence requirements](repository-intelligence-acceptance.md), source-preservation evidence in [the external audit](legacy-destination-evidence.md), and unresolved release obligations in [the candidate declaration](release-completion-status.json). Do not add command families merely to improve coverage counts.

Implementation and qualification are separate. Run deterministic contracts and exact packed-install checks, then qualify supported hosted environments and authorized agent/human outcomes. Controlled effectiveness claims require the [preregistered study](agent-study-contract.md). No model trials are part of history preparation.
